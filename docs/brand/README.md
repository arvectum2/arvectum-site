# Brand source assets

This directory stores heavyweight source/reference brand artwork that is not required by the production website.

Runtime web assets belong in `public/assets/brand/` and are subject to the repository asset budget.

Canonical runtime logo: `public/assets/brand/arvectum-logo-header-light.svg`.
Canonical square mark: `public/assets/brand/monogram.svg`.

Do not copy source PNG artwork back into `public/` unless the website actually references it and the asset checks remain green.
