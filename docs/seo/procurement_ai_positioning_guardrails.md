# Procurement AI Positioning Guardrails

## Target niche
AI agents for procurement and tenders (ИИ-агенты для закупок и тендеров).

## Core product formula
> **ИИ-агенты для закупок и тендеров.**
> RFQ, ТКП, экономика, риски, документы и статусы в одном контролируемом маршруте.
> MVP одного сценария за 2–4 недели.

## Repository separation
- **Implementation target:** `arvectum2/arvectum-site` — website code only
- **Reference only (do not modify):** `arutyunoveth/ai-corporation` — product-core repository

## Forbidden claims
Do NOT write or imply:
- fully autonomous tender participation
- automatic bid submission to procurement platforms
- electronic signature automation
- guaranteed tender wins
- guaranteed legal correctness
- complete replacement of procurement/tender department
- uncontrolled supplier communications
- direct integration with every ETP out of the box
- use of external AI services without restrictions
- "AI makes final decision"

## Required human-control statement
> На MVP человек утверждает решения, внешние отправки и подача заявок остаются ручными, а AI работает в ограниченном, проверяемом и журналируемом контуре.

## Safe wording examples
| Instead of | Use |
|---|---|
| AI автоматически подаёт заявку | AI готовит аналитику и черновики для утверждения человеком |
| Полная автоматизация тендеров | Контролируемый AI-маршрут с человеческим контролем |
| Гарантия победы | Помощь в подготовке материалов для решения об участии |
| Замена отдела закупок | Сокращение ручной работы по анализу и подготовке |

## Differentiation
| Generic market | Arvectum target position |
|---|---|
| Automate everything | Start with one procurement/tender scenario |
| Configure CRM/BPM/RPA | Build a controlled AI-agent workflow |
| Sell implementation hours | Sell an MVP route and measurable operational relief |
| Vague AI promises | Human-reviewed outputs, logs, restrictions and clear boundaries |
| Tool-first | Procurement operator role-first |

## MVP framing
- Start with one procurement/tender scenario
- Map inputs and decision points
- Configure workflow and prompts
- Test on historical or pilot tenders
- Run human-reviewed pilot
- Measure time saved and quality of outputs
- 2–4 weeks is an estimate, not a guarantee
