Политика конфиденциальности приложения «Фото под размер»

Редакция от 3 октября 2026 года

Правообладатель приложения — ООО «Арвектум».

1. Обработка фотографий

«Фото под размер» работает только с изображениями, которые пользователь самостоятельно выбирает через системный интерфейс iOS или Android. Обработка изображения выполняется локально на устройстве. Содержимое выбранных фотографий не загружается на серверы ООО «Арвектум» и не передаётся рекламному SDK.

2. Учётные записи и серверная обработка

  • регистрация и пользовательский аккаунт не требуются;
  • собственного backend для обработки изображений нет;
  • исходные фотографии на серверах ООО «Арвектум» не хранятся;
  • приложение не запрашивает доступ ко всей медиатеке устройства.

3. Реклама в iOS-версии

В iOS-версии используется Yandex Mobile Ads SDK для показа рекламы. Реклама поддерживает бесплатное распространение приложения и может показываться независимо от выбора пользователя в настройках рекламных данных.

При первом запуске пользователь выбирает, разрешать ли Yandex Mobile Ads обработку данных для рекламы. Выбор сохраняется локально и передаётся SDK при последующих запусках. Отказ от обработки рекламных данных не отключает рекламу.

Если пользователь разрешил обработку рекламных данных, iOS может отдельно показать системный запрос App Tracking Transparency (ATT). Только при системном разрешении ATT рекламному SDK становится доступен рекламный идентификатор IDFA. При отказе ATT реклама продолжает показываться без доступа к IDFA.

Передача геолокации в Yandex Mobile Ads отключена. Приложение не запрашивает разрешение геолокации для рекламы.

4. Управление согласием и отслеживанием

Изменить выбор для Yandex Mobile Ads можно внутри приложения через ссылку «Реклама и конфиденциальность». Системное разрешение ATT после первого ответа изменяется в настройках iOS. Эти настройки не отключают сам показ рекламы.

5. Сохранение и временные файлы

Исходный файл не изменяется. Результат сохраняется только по команде пользователя либо передаётся через системное меню «Поделиться». Временные рабочие файлы могут находиться в локальном кэше приложения и удаляться операционной системой или самим приложением.

6. Подключение к интернету и третьи лица

Основная функция обработки фотографий не требует интернета. В iOS-версии интернет используется для загрузки и измерения рекламы через Yandex Mobile Ads SDK и связанные компоненты. ООО «Арвектум» не передаёт содержимое фотографий в рекламную сеть.

Обработка данных рекламным SDK регулируется также применимыми документами и настройками Яндекса. ООО «Арвектум» не хранит IDFA или данные рекламного профиля на собственных серверах.

7. Права пользователя и обращения

Отозвать или изменить рекламное согласие можно средствами приложения, а разрешение ATT — средствами iOS. По вопросам конфиденциальности и обработки данных можно обратиться по адресу info@arvectum.com.

8. Изменения политики

Политика обновляется при изменении функциональности приложения, состава подключённых сервисов или применимых требований.

Photo Resize privacy policy

Effective October 3, 2026

The app is provided by LLC ARVECTUM.

1. Photos

Photos are selected explicitly through the iOS or Android system picker and processed locally on the device. Photo contents are not uploaded to Arvectum servers and are not sent to the advertising SDK.

2. Ads and device data on iOS

The iOS app uses Yandex Mobile Ads SDK. Ads remain enabled regardless of the user's advertising-data choice. On first launch the user can allow or decline advertising-SDK data processing; that choice is stored locally and supplied to the SDK on later launches.

If advertising-data processing is allowed, iOS may separately show the App Tracking Transparency (ATT) prompt. IDFA is available to the advertising SDK only when ATT permission is granted. If ATT is denied, ads still appear without IDFA access. Location forwarding to Yandex Mobile Ads is disabled and the app does not request location permission for advertising.

3. Privacy choices

The Yandex advertising-data choice can be changed from “Ads & Privacy” inside the app. ATT permission can be changed in iOS Settings after the system prompt has been answered. Neither choice creates an ad-free mode.

4. Storage and network use

The source file is not modified. Output is saved or shared only on the user's command. Temporary working files may remain in the local app cache until removed by the operating system or the app. Internet access is not required for image processing; on iOS it is used to load and measure ads through Yandex Mobile Ads and related components. Arvectum does not store IDFA or advertising-profile data on its own servers.

5. Contact

Privacy questions can be sent to info@arvectum.com.
