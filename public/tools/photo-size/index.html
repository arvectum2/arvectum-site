Фото под размер

Бесплатная утилита для сжатия фото и PDF до заданного лимита в КБ/МБ, изменения размера изображения и подготовки технических параметров некоторых фотографий для документов. Файлы обрабатываются на iPhone. При сильном сжатии PDF текст может перестать выделяться.
